# twoByFour

A notepad calculator for construction, for Mac and iPhone. Type `8' 9 1/2" - 2 × 3/4"` and get a
tape-measure answer; type `105"` and click the result for inches, feet and
metric. It does exact feet-inch-fraction math, so `10' / 3` is exactly `3' 4"`,
and it says `≈` whenever it had to round.

Coming next: the real sizes behind names like `2x4`, `3/4 ply`, `16d` and
`1/2" NPT`, carpenter rules of thumb, and lookups for units it doesn't know.

## Install

Download `twoByFour.zip` from [Releases](https://github.com/kylefritz/twobyfour/releases),
drag `twoByFour.app` into `/Applications`, then run
`xattr -dr com.apple.quarantine /Applications/twoByFour.app` (it isn't
notarized). It updates itself. **Settings → Every beta** follows each build of
`main`; **twoByFour → Try a Build…** switches to a pull request's preview build
(enter its number) or back (`beta`, `stable`). Press **⌃⌥Space** anywhere to
bring the notepad forward.

## Build

Needs macOS 26 and the Xcode Command Line Tools.

```sh
make test   # run the tests
make app    # build build/twoByFour.app
make install
scripts/release.sh 0.1.0   # tag a release; GitHub Actions builds it
```

See `docs/superpowers/specs/` for the design.

## iPhone app

`iOS/` holds the iPhone app: the same engine and sheets, with a carpenter
keypad in place of the keyboard. Its Xcode project is generated by
[XcodeGen](https://github.com/yonaskolb/XcodeGen) from `iOS/project.yml` and
isn't committed. Needs Xcode and `brew install xcodegen`.

```sh
make ios-project   # generate iOS/twoByFour.xcodeproj (open it to run on a phone)
make ios-test      # unit and UI tests in the simulator (IOS_SIM="iPhone 17" by default)
make ios-icon      # redraw the icon from the Mac app's drawing
```

Every commit on `main` that passes CI goes to TestFlight
(`.github/workflows/testflight.yml`, via `scripts/testflight.sh`), once these
one-time steps are done on the Apple Developer account (team `75W4LUJ7MW`):

1. **App ID.** developer.apple.com → Identifiers → + → App IDs → App:
   bundle ID `io.github.kylefritz.twobyfour` (explicit), description twoByFour.
2. **App record.** appstoreconnect.apple.com → Apps → + → New App: iOS, name
   twoByFour (any unused name works if it's taken; the home-screen name stays
   twoByFour), that bundle ID, SKU `twobyfour`.
3. **Distribution certificate.** Xcode → Settings → Accounts → Manage
   Certificates → + → Apple Distribution. Then Keychain Access → My
   Certificates → right-click "Apple Distribution: …" → Export as
   `dist.p12` with a password.
4. **Profile.** developer.apple.com → Profiles → + → App Store Connect, that
   App ID, that certificate, named exactly `twoByFour App Store`. Download it.
5. **API key.** App Store Connect → Users and Access → Integrations → App
   Store Connect API → + with the **App Manager** role. Download the `.p8`
   (only offered once); note the Key ID and Issuer ID.
6. **GitHub secrets** (from files, never pasted into a chat):

   ```sh
   gh secret set ASC_KEY_ID --body "<key id>"
   gh secret set ASC_ISSUER_ID --body "<issuer id>"
   base64 -i AuthKey_XXXX.p8 | gh secret set ASC_KEY_P8
   base64 -i dist.p12 | gh secret set IOS_DIST_CERT_P12
   gh secret set IOS_DIST_CERT_PASSWORD   # prompts
   base64 -i twoByFour_App_Store.mobileprovision | gh secret set IOS_PROFILE
   ```

Then install TestFlight on the phone; builds show up there for the account
that owns the app. To upload by hand instead, with the certificate and profile
installed: `ASC_KEY_PATH=… ASC_KEY_ID=… ASC_ISSUER_ID=… scripts/testflight.sh 0.0.1 1`.
